# Template library

Eight PNG contact sheets, two per family. Each sheet contains four complete
compositions in a 2×2 grid, for 32 selectable designs. Open both sheets in the
relevant family and choose a panel by ID and position as a visual reference.
Borrow its palette, linework, gradients, shadows and detail while designing the
layout around the user's content. Panel shapes, positions and layer counts are
flexible unless the user explicitly requests a particular layout.

Panel positions on each sheet: upper left, upper right, lower left, lower right.
The manifest records file dimensions, hashes, panel titles and positions.

Examples illustrate structures and composition. Chart values are synthetic
demonstrations, not measured evidence. Rebuild quantitative marks from the user’s
actual data. Do not copy sheet headings, IDs or example claims into user figures.
