# General logic

Open [sheet 01](../assets/logic-01.png) and [sheet 02](../assets/logic-02.png).
Each sheet contains four complete compositions in a 2×2 grid. Read left to
right, top to bottom. Sheet 01 contains 01–04; sheet 02 contains 05–08.

| ID | Panel | Appropriate relationship |
| --- | --- | --- |
| G01 | 反馈驱动闭环 | A sequence whose results feed into the next iteration |
| G02 | 双向协作模型 | Explicit requests and feedback between two parties |
| G03 | 平台协同网络 | Peer relationships and common support without invented sequence |
| G04 | 阶段推进与交付 | Ordered stages, outputs and a specific revision path |
| G05 | 三元协同体系 | Three factors contributing to one shared outcome |
| G06 | 双循环学习体系 | Two internal loops exchanging information |
| G07 | 目标拆解与支撑 | Goals decomposed into strategies and actions |
| G08 | 输入转化与输出 | Source content transformed into distinct output forms |

Borrow the reference's fine connector treatment, compact annotations, translucent
surfaces and subtle shadows. Design the relationship model from the source:
sequences, branches, peer networks and feedback need their own geometry. Rings,
pyramids and node positions are optional unless explicitly requested. Maintain
clear visual hierarchy between the main relationships and supporting detail.

Specify every arrow's source, target and meaning. A ring or radial layout does
not itself imply a closed loop or causal link. Keep terminal delivery terminal
unless a return is stated. Route revision separately from the forward path and
check arrow directions after rendering. Use unarrowed membership lines when the
source specifies only association. Sample labels are not facts to carry over.
