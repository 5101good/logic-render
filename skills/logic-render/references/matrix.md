# Tables and architecture matrices

Open [sheet 01](../assets/matrix-01.png) and [sheet 02](../assets/matrix-02.png).
Each sheet contains four complete compositions in a 2×2 grid. Read left to
right, top to bottom. Sheet 01 contains 01–04; sheet 02 contains 05–08.

| ID | Panel | Appropriate relationship |
| --- | --- | --- |
| M01 | 产品能力全景 | Product roles, scenarios, capabilities and resources |
| M02 | 系统架构分层 | System responsibilities, modules and governance boundaries |
| M03 | 方案能力对比 | Options compared on common qualitative dimensions |
| M04 | 跨角色流程泳道 | Work and deliverables moving across responsible actors |
| M05 | 端到端业务协作 | A complete business chain with tasks and outputs |
| M06 | 数据治理流转 | Data sources, transformation, services and quality controls |
| M07 | 服务能力分区 | Capability domains and shared services for multiple clients |
| M08 | 组织与职责协同 | Team responsibilities, collaboration and shared mechanisms |

Keep the reference's compact blue header bands, white submodules, very fine
rules, dashed group boundaries, subtle shadows and precise alignment. Choose
rows, columns, groups and supporting annotations from the actual comparison or
responsibility model. Restructure the grid freely unless its layout is explicitly
requested. Size cells to fit their content and keep matrices front-facing.

For comparisons, each row uses one common dimension. Missing information is
unknown, not zero. Do not invent scores or imply an unexplained winner. For
system matrices, rebuild all dependencies from the source. Sample capabilities,
team assignments and products are illustrative and must be replaced.
