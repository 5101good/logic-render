# Visual system

## Use the library as a visual reference

The library has eight PNG contact sheets, two per family, with four panels each.
Open both sheets in the chosen family before selecting a panel. Positions read
left to right, top to bottom. Choose a primary panel by ID and position to anchor
the visual treatment. Compatible details from another panel may inform the same
coherent figure.

Build the composition from the source's entities and relationships. Freely change
the silhouette, proportions, positions, layer count, module shapes and connector
paths. A layered reference can lend its finish to a peer network or branching
process without imposing a stack of platforms. Use stacking to communicate a
supported hierarchy and show feedback only where a return relationship exists.

| User request | Layout rule |
| --- | --- |
| General request, a panel ID, or “参考这个模板/风格” | Use the reference's visual language and design quality; compose freely around the content. |
| Explicitly keep or reproduce a particular layout | Retain the requested layout features. Surface conflicts with the source instead of inventing facts to fit. |

Carry these properties into the final figure:

- **Visual hierarchy:** a clear focal point, balanced negative space, precise
  alignment and readable main/secondary detail. Place groups and annotations
  according to the source and the needs of the new figure.
- **Material:** translucent blue surfaces, hairline bright edges, delicate gradients
  and layered subtle shadows where the selected panel uses them. Use thin planes,
  precise edges and controlled depth.
- **Depth:** consistent perspective and separated planes for conceptual layers;
  precise front-facing geometry for matrices and quantitative charts.
- **Typography:** compact explanatory title, legible dark labels, short blue
  callouts and careful alignment. Use a licensed sans-serif font with Chinese
  coverage when rendering text deterministically.
- **Connections:** fine blue leaders and intentional directional arrows. Leaders
  label objects; arrows express source-supported relationships.

Retain the richness of the reference's linework, color transitions, material and
supporting detail in the new composition. Freedom to change structure does not
justify reducing the result to undifferentiated flat boxes or a single blue tint.
User-supplied references and explicit style requests override library defaults.

## Palette and finish

| Role | Default |
| --- | --- |
| Background | ice white `#F5F8FF` / white |
| Main text | navy `#122443` |
| Deep anchors / shadow sides | indigo `#2633B6` |
| Core structures | cobalt `#2855F2` |
| Supporting planes | azure `#288DE7` |
| Light-facing edges / transitions | cyan `#67CFF1` |
| Distant planes / ambient shadows | ice lavender `#D5DCFF` |
| Quiet surfaces | pale blue `#E8F2FF` / near white |
| Fine borders | `#BCD4F5` |

Establish a saturated structural anchor, a distinct midtone supporting layer,
and a quiet pale background in each composition. Vary hue as well as brightness:
cyan-to-azure transitions, cobalt-to-indigo front edges, and pale lavender shadow
planes. Separate thin bright top faces from darker front edges and undersides.
Adjacent layers must remain distinguishable at thumbnail size. Keep shadows
soft but visible, and preserve fine contour lines and internal divisions.

Matrices use graded blue header bands, white cells, fine rules and dashed group
boundaries. Different tiers or semantic groups can have distinct cyan, cobalt and
indigo accents. Chart series use distinguishable colors with consistent legends;
data marks remain flat and proportional. Texture
must not distort encoded area, angle or length. C08 is an explicit dark navy and
blue-violet variant. Do not apply its dark treatment to other panels by default.

## Size and density

Default finished figures to 16:9 unless the user specifies another ratio.
The landscape contact sheets are model-facing selection catalogs; normally output
one complete custom figure. Output a contact sheet only when the
user asks for a template collection or multiple compositions in one image.

Keep titles modest (roughly 4–6% of canvas height), with 4–6% outer margins.
Use 4–8 main labels where possible. For mobile articles, preview at the intended
reading width; split dense material into overview and details rather than shrinking
essential labels. High resolution alone does not fix cramped composition.

## Visual acceptance

Compare the output side by side with the reference: color hierarchy, depth,
gradients, connector weight, typography, detail and whitespace should belong to
the same design system. Evaluate composition against the user's relationships
and reading needs; matching the reference's arrangement is required only for an
explicit layout request. Verify facts, labels and arrow directions alongside
visual consistency.
